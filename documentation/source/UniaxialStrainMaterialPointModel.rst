************************************
Uniaxial Strain Material Point Model
************************************
MatCal's :class:`~matcal.sierra.models.UniaxialStrainMaterialPointModel`
is meant to be used in calibrations that can use a material point
model subject to uniaxial strain loading as the simulation of the experiment.
This can be a valid model for laterally confined experiments such as confined
compression or plate impact, where the material is prevented from expanding or
contracting normal to the loading direction. The
:class:`~matcal.sierra.models.UniaxialStrainMaterialPointModel` model has most of the MatCal standard
model features as described in :ref:`MatCal SIERRA Solid Mechanics Standard Models`. Due to
the local nature of the model, only adiabatic thermomechanical loading is supported,
and implicit dynamics is not supported.

This model shares its geometry, loading function determination and thermal behavior
with the :ref:`Uniaxial Stress Material Point Model`. Only the lateral boundary
conditions and the model output differ, and those differences are described here.

.. warning::
    The lateral confinement of uniaxial strain produces a large hydrostatic pressure
    and a stress triaxiality very different from uniaxial stress. Material models
    with pressure or triaxiality dependent plasticity or damage, as well as element
    death criteria, may behave very differently than in the
    :ref:`Uniaxial Stress Material Point Model`. As with that model, stress and
    strain values must be negative for compression and positive for tension.

Uniaxial strain material point boundary conditions
==================================================
The boundary conditions load the hexahedral element in a uniaxial strain state,
in which the only nonzero strain component is in the loading (Z) direction.
They include:

#.  Displacement boundary conditions on the nodes of all four surfaces parallel
    to the loading direction that are fixed in the directions normal to the surfaces
    on which they are applied. These prevent lateral contraction or expansion.
#.  A displacement boundary condition fixed normal to the loading direction on
    the nodes on the bottom surface of the element.
#.  An applied displacement function that varies with time to the nodes on the top
    of the element. The function is determined the same way as for the
    :ref:`Uniaxial Stress Material Point Model`.

Because every lateral face is constrained, no additional constraint is needed
to prohibit rigid body modes.

Uniaxial strain material point model output
===========================================
By default, the uniaxial strain material point model includes the following global
output fields:

#. time
#. displacement - measured in the loading direction at the nodes with the applied displacement function
#. load - measured at the applied boundary condition nodes in the loading direction.
#. engineering_strain - same as displacement
#. engineering_stress - same as load
#. true_strain - the log strain of the element in the loading direction
#. true_stress - the Cauchy stress of the element in the loading direction
#. temperature - the element temperature
#. log_strain_xx/yy - the log strain of the element in the directions normal to the loading direction.
   These should remain zero and are useful for verifying the constraint.
#. cauchy_stress_xx/yy - the Cauchy stress of the element in the directions normal to the loading
   direction, which is generated by the lateral confinement.

Unlike the :ref:`Uniaxial Stress Material Point Model`, no contraction output is
provided since lateral displacement is prescribed to be zero.
All element values are output from the average of all values at element integration points.
