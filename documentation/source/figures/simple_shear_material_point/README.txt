Simple Shear Material Point Model Figure

This directory should contain a figure showing the boundary conditions for the
Simple Shear Material Point Model.

Required file: simple_shear_material_point_model_bcs.png (or .pdf)

The figure should show:
- A unit cube (1x1x1) hexahedral element
- Bottom surface (ns_negative_z): Fixed in X, Y, Z directions (shown with fixed constraints)
- Top surface (ns_positive_z): 
  * Applied displacement in X direction (shown with arrow)
  * Fixed in Y and Z directions (shown with constraints)
- Coordinate system showing X, Y, Z axes
- Shear deformation visualization showing the top surface displaced in +X direction
